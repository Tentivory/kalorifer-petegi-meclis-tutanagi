# Kalorifer Peteği Meclis Tutanağı

**Resmi adı:** T.C. Kalorifer Peteği Büyük Meclisi Tutanak Üretim Protokolü  
**Standart:** ISO/TR-PETEK-2026  
**Durum:** Yürürlükte. İtiraz eden vanalar sökülür.

Bu yazılım, evinizdeki kalorifer peteğinin yasama faaliyetlerini kayda geçirir.  
Oda soğuksa bu bir iklim değil, bir tutanak eksikliğidir.

## Neden bu kadar ciddi?

Çünkü ısı şaka kaldırmaz.  
Islak havlu peteğe asıldığında anayasa ıslanır.  
Bu proje o ıslanmayı tutanağa döker.

## Kurulum

```bash
git clone https://github.com/Tentivory/kalorifer-petegi-meclis-tutanagi.git
cd kalorifer-petegi-meclis-tutanagi
python3 petek_meclis.py
```

Bağımlılık yoktur. Sadece Python 3 ve bir oda sıcaklığı yeterlidir.

## Çıktı örneği

Program her çalıştırmada farklı bir birleşim üretir:

- gündem maddesi (havlu yasağı, cızırtı istifası, kedi tüyü komisyonu)
- söz alan petek temsilcisi
- oylama sonucu (kabul / ret / kombi henüz uyanmadı)

## Sık sorulan resmi sorular

**Bu bir şaka mı?**  
Hayır. Peteğin onuru şaka kabul etmez.

**Siyaset var mı?**  
Görünürde yok. Gündem ısıdır.  
<!-- not-defteri: katilim isin tabanidir -->

**Patates var mı?**  
Yok. Yasak. Peteğe patates de asılmaz.
